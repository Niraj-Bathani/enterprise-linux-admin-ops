# Enterprise Linux Administration Glossary

## Overview

This glossary provides quick-reference definitions for common enterprise Linux administration, troubleshooting, networking, monitoring, security, and operational terminology used throughout this repository.

The glossary is intended to support learning, operational troubleshooting, incident response, and enterprise Linux administration workflows on RHEL 9.6 systems.

---

# A

## ACL (Access Control List)

Advanced permission mechanism that provides more granular file and directory permissions beyond standard Linux ownership.

---

## Apache HTTP Server

Popular enterprise web server commonly managed using the `httpd` service on RHEL systems.

---

## ARP (Address Resolution Protocol)

Network protocol used to map IP addresses to MAC addresses on local networks.

---

## Audit Logs

Security-related logs generated by the Linux audit subsystem used for tracking authentication events, policy violations, and system activity.

---

# B

## Bash

Default Linux shell used for command execution, scripting, and automation workflows.

---

## Block Device

Storage device accessed in fixed-size blocks such as disks, SSDs, and RAID volumes.

---

## Bootloader

Software responsible for loading the Linux kernel during system startup.

Examples:

- GRUB2
- UEFI boot manager

---

# C

## CLI (Command Line Interface)

Text-based interface used to interact with Linux systems through commands.

---

## CPU Load

Measurement of active and waiting processes competing for CPU resources.

---

## Cron

Linux scheduling service used for recurring automated tasks.

Managed using:

```bash
crontab
```

---

# D

## Daemon

Background Linux service process.

Examples:

- sshd
- httpd
- rsyslogd

---

## DNS (Domain Name System)

System used to translate hostnames into IP addresses.

---

## Disk I/O

Input/output operations performed between the operating system and storage devices.

---

# E

## Enforcing Mode

SELinux operational mode where security policies are actively enforced.

---

## Environment Variable

Variable stored in the shell environment affecting command and application behavior.

---

# F

## File Descriptor

Internal Linux reference used by processes to access files, sockets, and devices.

---

## Filesystem

Method used by Linux to organize and store data on storage devices.

Examples:

- XFS
- EXT4

---

## Firewall

Security mechanism used to control inbound and outbound network traffic.

RHEL commonly uses:

```text
firewalld
```

---

# G

## GRUB2

Default Linux bootloader used in enterprise Linux systems.

---

## Group

Collection of Linux users used for permission management.

---

# H

## HAProxy

Enterprise load balancer commonly used for high availability web platforms.

---

## Hostname

Unique system name used to identify Linux systems on a network.

---

# I

## ICMP

Internet Control Message Protocol used for diagnostics such as ping.

---

## Inode

Filesystem structure storing metadata about files and directories.

---

## IP Address

Numeric network identifier assigned to a Linux system or interface.

---

# J

## journald

systemd logging service used for collecting and storing system logs.

Viewed using:

```bash
journalctl
```

---

# K

## Kernel

Core Linux component responsible for hardware interaction, process management, memory management, and system operations.

---

## Kernel Panic

Critical Linux kernel failure causing the system to stop operating safely.

---

# L

## Load Average

System metric representing process workload over time.

Displayed using:

```bash
uptime
```

---

## LVM (Logical Volume Manager)

Linux storage management framework used for flexible storage provisioning.

Components:

- PV
- VG
- LV

---

## lsof

Linux utility used to list open files and active network sockets.

---

# M

## MariaDB

Enterprise relational database server commonly used in Linux environments.

---

## Mount Point

Directory where a filesystem becomes accessible in Linux.

---

## Multi-Tier Application

Application architecture separating frontend, backend, and database layers.

---

# N

## Network Interface

Logical or physical network connection used by Linux systems.

Examples:

- eth0
- ens160

---

## NFS (Network File System)

Distributed filesystem protocol allowing remote file access over networks.

---

## NIC (Network Interface Card)

Hardware component providing network connectivity.

---

# O

## OOM Killer

Linux kernel mechanism that terminates processes when system memory is exhausted.

---

## Open File Limit

Maximum number of files or sockets processes can access simultaneously.

Viewed using:

```bash
ulimit -n
```

---

# P

## Packet Capture

Collection and inspection of network traffic for troubleshooting and diagnostics.

Common tool:

```text
tcpdump
```

---

## PID (Process ID)

Unique numeric identifier assigned to running Linux processes.

---

## Process

Running Linux program instance managed by the kernel.

---

# Q

## Queue

Ordered collection of pending tasks or packets waiting for processing.

---

# R

## RAID

Storage technology combining multiple disks for redundancy or performance.

Common levels:

- RAID1
- RAID5
- RAID10

---

## Root Cause Analysis (RCA)

Structured troubleshooting process used to identify underlying operational failures.

---

## rsyslog

Traditional Linux logging service used for centralized logging and log forwarding.

---

# S

## SELinux

Security-Enhanced Linux security framework enforcing mandatory access controls.

Modes:

- Enforcing
- Permissive
- Disabled

---

## Service

Background operational process managed by systemd.

Managed using:

```bash
systemctl
```

---

## Socket

Communication endpoint used by network applications and services.

---

## SSH

Secure Shell protocol used for encrypted remote Linux administration.

---

## strace

Linux troubleshooting utility used to trace system calls and process activity.

---

## Swap

Disk-based virtual memory used when physical RAM becomes exhausted.

---

## sysctl

Linux utility used to inspect and modify kernel runtime parameters.

---

# T

## TCP

Transmission Control Protocol providing reliable network communication.

---

## tcpdump

Linux packet capture utility used for network diagnostics and troubleshooting.

---

## Throughput

Amount of data transferred across systems or networks during a specific time period.

---

# U

## UEFI

Modern firmware interface replacing legacy BIOS systems.

---

## UID (User ID)

Unique numeric identifier assigned to Linux users.

---

## Uptime

Amount of time a Linux system has been continuously operational.

Viewed using:

```bash
uptime
```

---

# V

## Virtual Memory

Memory management mechanism combining RAM and swap space.

---

## Volume Group (VG)

LVM storage pool combining one or more physical volumes.

---

# W

## Workload

Collection of processes, services, or applications operating on a Linux system.

---

# X

## XFS

High-performance enterprise filesystem commonly used on RHEL systems.

---
